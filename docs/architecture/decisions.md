# Architecture decisions

Deliberate deviations from the Adaptive Convergence v3 Web Manual and the project brief, and work that is deferred to a later slice. Add an entry whenever a rule is bent; remove it when its follow-up lands.

## Bootstrap (2026-10-12)

| # | Decision | Why | Follow-up |
|---|---|---|---|
| 1 | The layout follows manual §4.2: `contract/`, `backend/`, `web/`, `design/`, `infra/`. It does not use the brief's `apps/web` + `apps/api` + `packages/` layout. | The manual is the method being applied. `web/` matches the manual's paths, CODEOWNERS and `.gitattributes`. The root `CLAUDE.md` tree says `frontend/`, but its own placement table says `web/`. | Align the `CLAUDE.md` tree with `web/`. |
| 2 | API base is `/api/v1/`, declared once in `AC_CONTRACT["api_base"]` and exported as `meta.apiBase`. | The manual's `/api/v3` is the manual's edition, not this API's version. URL routing and clients both derive from the contract. | None |
| 3 | The contract `meta` has no `sourceCommit`. | A commit hash in the artefact changes on every commit, so the drift check could never pass. | Stamp the commit in release notes or image labels. |
| 4 | The version-bump rule is enforced by `contract export`; `contract check` verifies that the committed artefact equals a fresh export. | After an export, committed and fresh are identical, so a check-time comparison (as in the manual) cannot see what changed. | Add a CI step that classifies the diff against the base branch's artefact. |
| 5 | Built-in `django.tasks` (Django 6.0+) instead of the `django-tasks` backport. `ImmediateBackend` in dev, `DummyBackend` in CI. | `django-tasks` 0.12 moved its database backend out into `django-tasks-db`, and Django 6.1 already provides the API. | Choose a durable backend and add a `worker` compose service with the first enqueued work (SM-F-21 or SM-F-05). |
| 6 | `livekit-api` and `livekit-client` are not installed. | No SokoMesh requirement involves video or voice. | None |
| 7 | ESLint uses `eslint-plugin-boundaries` v7 `boundaries/dependencies` policies. | v7 replaced the manual's `boundaries/element-types` syntax. The manual's `ac/no-model-literals` rule does not exist as a package. | Write a local rule once the kernel exists to lint; until then the PR checklist covers it. |
| 8 | Postgres is published on host port 5433. | Port 5432 is already in use by a local Postgres install. | None |
| 9 | Tailwind's default colour palette and radius scale are cleared. | Only brand tokens can be expressed, which blocks off-brand colours and radii. | None |
| 10 | pyright runs with `django-stubs`. `reportArgumentType` is disabled only in `config/settings/*`. | django-environ types every `default=` as `NoValue`. Settings are the boundary where environment values are narrowed. | Remove the suppression if django-environ ships accurate types. |
| 11 | Generators are ESM `.mts`, split into pure render modules (`tools/contract.mts`, `tools/tokens.mts`) and small entry scripts. | Unit tests can exercise rendering without writing files. | None |

| 65 | The media pipeline (SM-F-05) has no image library: it reads dimensions from the container header, refuses images over `AC_MEDIA["max_pixels"]` or with a long side under `min_long_side`, strips metadata (EXIF, GPS, XMP, IPTC, comments, text chunks) by rewriting the JPEG, PNG or WebP container without decoding, and stores that copy as the public display image.
